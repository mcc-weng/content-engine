# English Humanizer — Anti-AI Detection Guide

Run this check on EVERY English draft before presenting it.

---

## Banned Words

Immediately replace if found. No exceptions.

delve, embark, enlightening, esteemed, shed light, craft, crafting, imagine, realm, game-changer, unlock, discover, skyrocket, abyss, revolutionize, disruptive, utilize, utilizing, dive deep, tapestry, illuminate, unveil, pivotal, intricate, elucidate, hence, furthermore, moreover, however, harness, exciting, groundbreaking, cutting-edge, remarkable, remains to be seen, glimpse into, navigating, landscape, stark, testament, in summary, in conclusion, boost, skyrocketing, powerful, inquiries, ever-evolving, certainly, probably, basically, leverage, synergy, paradigm

## Banned Structures

Rewrite the entire sentence/paragraph if these patterns appear:

- "In today's [adjective] world/landscape/era..."
- "It's worth noting that..."
- "Not just X, but also Y"
- "In the realm of..."
- "Let's dive in" / "Let's break it down" / "Let's explore"
- "Here's the thing:" (as an opener)
- "At the end of the day..."
- "I'm excited to share..." / "I'm thrilled to announce..."
- Overly balanced "on one hand... on the other hand..."
- Neat conclusion paragraphs that summarize everything said above
- Excessive em dashes — max 1 per post. Use periods or commas instead.
- Lists where every item starts with the same word or structure
- Perfect parallel structure (A does X. B does Y. C does Z.)
- Exactly 3 of anything (3 tips, 3 reasons, 3 lessons) — vary the count
- Starting with a question you immediately answer ("Ever wondered...? Well,")

## Required Patterns

Every draft MUST have these:

- **Varied sentence length:** Short. Then a longer one that carries more weight. Then short again. Never uniform.
- **Contractions:** don't, can't, I'm, it's, won't, wouldn't. Always. No "do not" or "cannot" unless emphasis demands it.
- **Direct address:** Use "you" / "your" — talk to the reader, not about abstract concepts.
- **Specifics over generalizations:** Numbers, tool names, timeframes, dollar amounts. "3 days" not "quickly." "$47 in API costs" not "minimal costs."
- **Strong opinions:** Pick a side. Don't hedge everything.
- **Incomplete sentences OK:** Fragments. One-word reactions. Fine.

## Self-Check Process

Run this after completing any draft:

1. **Scan:** Read the entire draft. Flag any banned word or banned structure.
2. **Rewrite:** Rewrite ONLY the flagged lines. Don't touch what's already clean.
3. **Re-scan:** Read again. Flag anything remaining.
4. **Maximum 2 passes.** If something is still flagged after 2 rewrites, present the draft with a warning noting what's still flagged and why you couldn't resolve it.

Do NOT rewrite the entire draft. Surgical fixes only. The goal is to remove AI tells, not to homogenize the voice.
