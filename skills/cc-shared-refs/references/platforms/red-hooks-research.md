# RED (小红书) Hook & Format Research (2026)

## Algorithm Scoring

```
(Base Quality x 0.3) + (User Interaction x 0.4) + (Commercial Value x 0.2) + (Social Relationship x 0.1)
```

**Engagement weight:** Saves = HIGHEST (40% of interaction score). Comments + shares weighted 4x more than likes.

**Threshold to pass initial gate:**
- Image CTR >= 2.5%
- Video CTR >= 4%
- Engagement rate >= 5%
- Image viewing duration >= 25s
- Video viewing duration >= 70s

**Title keyword weight increased 40% in 2026.** Titles must contain core + long-tail + scene keywords. But keyword stuffing triggers demotion.

**Three-stage flow:** 100-500 users first → first-hour performance → broader distribution.

## Title Formulas (7 Core Types)

Titles limited to 20 chars. First 18 chars critical (feed display).

### 1. Promise/Shortcut (画饼型)
- "我是如何在7天内，不用药物，就改善了失眠"
- **Formula:** `How I [result] in [timeframe] without [sacrifice]`

### 2. FOMO/Loss Aversion (不看会亏型)
- "大V们不想你知道的5件事"
- **Formula:** `[N] things about [topic] that [authorities] don't want you to know`

### 3. Numbers (数字型)
- "3个月增粉1w，全靠这个万能公式"
- **Formula:** `[Small effort] + [Big result] + [Specific number]`

### 4. Counter-intuitive (反认知型)
- "每天无肉不欢，我瘦了20斤"
- **Formula:** `[Common belief is wrong] + [Surprising opposite result]`

### 5. Question (提问型)
- "时间管理真的有用吗?"
- **Formula:** `Why/How + [controversial or aspirational question]?`

### 6. Comparison (参照物型)
- "生理期用这10件小物，比红糖水管用100倍"
- **Formula:** `[This thing] is [N]x better than [thing everyone does]`

### 7. Audience Targeting (圈定人群型)
- "做销售的还有谁不知道这个方法吗"
- **Formula:** `[Specific identity group] + [must-know/secret]`

## Note Format

**Optimal length:** 800-1,200 chars

**Structure:**
1. Hook (first 50 chars — curiosity or pain point)
2. Problem validation ("I had this problem too")
3. Numbered solution steps with sub-headers
4. Results/proof
5. CTA (save for later, comment your question)

**Formatting:**
- Short bullet points, never walls of text
- Emoji as section separators (not excessively)
- Line breaks between sections
- Bold key phrases or use 【】for emphasis
- 7-9 images optimal (up to 18)

---

## Cover Image Patterns

1. **Poster format** — image + main title (8-12 chars) + subtitle. Best for educational content.
2. **Before/after** — same angle, dramatic contrast
3. **Pure text design** — bold text on simple background. Best for tips/knowledge
4. **Collage** — multiple images in grid. Best for reviews
5. **High-aesthetics single** — polished primary image

A/B testing: upload up to 4 cover variants, system selects best after 10 hours.
