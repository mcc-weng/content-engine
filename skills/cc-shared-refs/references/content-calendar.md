# Content Calendar — The Honest Tinkerer

## Daily Prompts

These are fallback prompts for blank days — used when there's nothing in today's captures or the ideas backlog. The day-of-week theme is a suggestion, not a rule. If something better happened today, post that instead.

### X (English)

| Day | Prompt | Example |
|---|---|---|
| Mon | Show something you're building | Screen record a feature, explain what it does |
| Tue | Teach one thing you know | "Here's how I set up X in 5 minutes" |
| Wed | Share a struggle or mistake | "I wasted 2 hours on this because..." |
| Thu | React to something trending | Try a new tool, comment on AI news |
| Fri | What did you learn this week? | Weekly reflection, honest take |
| Sat/Sun | Free — post from backlog or skip | Rest days, no guilt |

### Instagram / RED

Same prompts as above — adapt language and format per platform module.

## Content Decision Priority

When suggesting what to post, check these sources IN ORDER:

1. **Today's captures** — read `content/ideas.md` for today's date entries. If something was logged today, suggest it first.
2. **Ideas backlog** — read `content/ideas.md` for items with `raw` or `concept` status. Suggest the oldest unposted idea.
3. **Daily prompt** — fall back to the day-of-week prompt above.

Never suggest "I don't know what you should post." Always have an answer from one of these three sources.

## Rules

- Trends override calendar — if major AI news drops, post about it
- Weekend posts are optional — no guilt for skipping
- Don't force a category if nothing fits — skip and post what feels right
- Same core story across platforms, adapted per audience — not translated
