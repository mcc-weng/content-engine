# Three-Pillar Scoring Rubric

Score every draft on three pillars after passing the anti-AI self-check. 3-point scale: Fail / Pass / Strong.

---

## Universal Framework

The three-pillar model applies to all platforms. Specific calibration varies by platform (see sections below).

### Hook
| Score | Description |
|-------|-------------|
| **Fail** | Generic opening. Could be anyone's post. No scroll-stop trigger. |
| **Pass** | Clear hook but could be sharper. Has a hook type but execution is predictable or vague. |
| **Strong** | Specific, unexpected, forces a reaction. You'd stop scrolling. First unit demands attention. |

### Retention
| Score | Description |
|-------|-------------|
| **Fail** | Flat structure. No rhythm variation. Wall of text. No progression or pull through the content. |
| **Pass** | Structure and pacing exist but momentum could be stronger. |
| **Strong** | Varied rhythm. Each unit pulls to the next. Open loops resolve satisfyingly. Can't stop mid-post. |

### CTA
| Score | Description |
|-------|-------------|
| **Fail** | No engagement prompt. Or disconnected generic prompt bolted on. Or obvious engagement bait. |
| **Pass** | CTA exists and relates to the post but feels slightly mechanical. |
| **Strong** | Ending flows so naturally you want to engage before thinking about it. Content and CTA are inseparable. |

## Threads Scoring

### Hook
| Score | Description |
|-------|-------------|
| **Fail** | Generic opening. "最近..." or "今天想分享..." — could be anyone's post. |
| **Pass** | Clear hook but could be sharper. Has a hook type but execution is predictable or vague. |
| **Strong** | Specific, unexpected, forces a reaction. First line demands attention. |

### Retention
| Score | Description |
|-------|-------------|
| **Fail** | Flat pacing. No rhythm variation. Wall of text. All sentences similar length. No open loops. |
| **Pass** | Structure and pacing exist but momentum could be stronger. Some variation but not enough pull. |
| **Strong** | Varied rhythm — short/long/short. Each line pulls to the next. Open loops resolve satisfyingly. Can't stop mid-post. |

### CTA
| Score | Description |
|-------|-------------|
| **Fail** | No engagement prompt. Or disconnected "你覺得呢？" bolted on. Or obvious engagement bait. |
| **Pass** | CTA exists and relates to the post but feels slightly mechanical. |
| **Strong** | Ending flows so naturally you want to reply before thinking about it. Content and CTA are inseparable. |

## RED Scoring

### Hook
| Score | Description |
|-------|-------------|
| **Fail** | Title has no keywords. First line doesn't create curiosity. Could be any generic note. |
| **Pass** | Title has keywords but first-line curiosity is weak. Gets found but doesn't pull readers in. |
| **Strong** | Title contains 2 core keywords in first 18 chars + creates a curiosity gap or clear promise. First line of body delivers on it. |

### Retention
| Score | Description |
|-------|-------------|
| **Fail** | No headers. Wall of text. No structure. Nothing scannable. Reader bounces before completing. |
| **Pass** | Has some structure but headers are weak or inconsistent. Completion rate would be moderate. |
| **Strong** | Clear headers break content into scannable sections. Each section earns the next. Structure drives completion, completions drive saves. |

### CTA
| Score | Description |
|-------|-------------|
| **Fail** | No engagement question. No save trigger. Post just ends. |
| **Pass** | Has an engagement question but it's generic ("你覺得呢?") or save trigger feels forced. |
| **Strong** | Save-driving ending: content is valuable enough that readers want to return to it. Engagement question is specific to the topic and genuinely curious. Both save + comment signals triggered. |

## Instagram Scoring

### Hook
| Score | Description |
|-------|-------------|
| **Fail** | Slide 1 doesn't answer "is this for me?" Vague or generic. Doesn't stop mid-scroll. |
| **Pass** | Slide 1 has a clear topic but doesn't immediately create desire to swipe. |
| **Strong** | Slide 1 answers "is this for me?" in under 12 words. Bold, specific, creates immediate desire to swipe. |

### Retention
| Score | Description |
|-------|-------------|
| **Fail** | No progression. Slides feel random. Nothing pulls from one slide to the next. Drop-off after slide 2. |
| **Pass** | Logical progression but some slides feel like filler. Not all slides earn the swipe. |
| **Strong** | Every slide earns the next swipe. Progression feels inevitable. Final slide lands with impact. Reader saves before thinking. |

### CTA
| Score | Description |
|-------|-------------|
| **Fail** | No CTA on final slide. Or CTA is generic "like and follow." Caption CTA disconnected from content. |
| **Pass** | Final slide has CTA but it's weak (too broad, too much friction). |
| **Strong** | Final slide drives save, DM, or share with a specific, low-friction ask directly tied to the content value. |

## X Scoring

### Hook
| Score | Description |
|-------|-------------|
| **Fail** | First line doesn't stop scroll. Generic opener. Could be anyone's tweet. |
| **Pass** | First line is clear but doesn't create urgency or curiosity. Noticeable but skippable. |
| **Strong** | First line stops scroll. Specific, unexpected, or provokes immediate reaction. Forces "I need to read this." |

### Retention
| Score | Description |
|-------|-------------|
| **Fail** | Single tweet: bloated, doesn't land. Thread: no pull between tweets, feels like one idea repeated. |
| **Pass** | Single tweet lands but could be tighter. Thread has logical flow but not all tweets earn the next. |
| **Strong** | Single tweet: every word earns its place, lands hard. Thread: each tweet delivers value AND pulls to the next. Hook tweet → body tweets → closing tweet all serve distinct roles. |

### CTA
| Score | Description |
|-------|-------------|
| **Fail** | No engagement prompt. Or asks generic "what do you think?" with no specific anchor. |
| **Pass** | Has a question or prompt but it's broad. Some replies but no strong conversation pull. |
| **Strong** | Drives reply or quote-tweet with a specific, opinionated prompt. Invites pushback or builds community (build-in-public angle). |

## LinkedIn Scoring

### Hook
| Score | Description |
|-------|-------------|
| **Fail** | First 210 chars (before "See more") are generic, slow, or start with "I wanted to share." No reason to click. |
| **Pass** | First 210 chars are clear but not compelling enough. Some will click, many won't. |
| **Strong** | First 210 chars hook with a contrarian claim, narrative drop, or specific statistic. Creates urgency to click "See more." |

### Retention
| Score | Description |
|-------|-------------|
| **Fail** | Long paragraphs. No whitespace. Wall of text. Unreadable on mobile. |
| **Pass** | Some paragraph breaks but inconsistent. Some sections too long. Not fully scannable. |
| **Strong** | Short paragraphs (2-3 sentences max). Aggressive line breaks. One idea per paragraph. Fully scannable. Reading momentum builds naturally. |

### CTA
| Score | Description |
|-------|-------------|
| **Fail** | No question. Post just ends. Or ends with "thoughts?" — too generic. |
| **Pass** | Has a question but it's broad. Some engagement but doesn't tap into professional expertise. |
| **Strong** | Question drives comments by inviting specific professional experience or expertise sharing. Specific enough that people feel qualified to answer. |

## Rewrite Rules

- Any pillar = **Fail** → auto-rewrite only the targeted lines:
  - **Hook Fail** → replace hook with a different hook type. Keep the rest intact.
  - **Retention Fail** → re-pace/restructure the body: vary lengths, add breaks, insert open loop if missing. Don't change hook or ending.
  - **CTA Fail** → replace closing unit. If integrated ending failed, try CTA bank. If bank failed, try integrated.
- **Max 2 rewrite passes.** If still Fail after 2 attempts, present to user with flag: "⚠️ [pillar] 我不太滿意，你看看要不要調"
- **Rewrite target is platform-specific:** Hook rewrites on RED target title keywords + first-line curiosity. Hook rewrites on LinkedIn target the first 210 chars. Hook rewrites on Instagram target Slide 1 text. Use the correct platform's scoring criteria when rewriting.

## Fail Calibration Examples

### Threads Fail Example

**Topic:** "I built an iOS app using Claude Code, no Swift experience"

**Fail version:**
```
最近用 Claude Code 做了一個 iOS app
不會寫 Swift 但還是做出來了
AI 真的很厲害
大家覺得呢？
```

Why each pillar fails:
- **Hook:** "最近用..." is generic. No numbers, no surprise, no scroll-stop.
- **Retention:** All sentences ~12 chars. Flat pacing. No open loop, no twist, no momentum.
- **CTA:** "大家覺得呢？" is the exact pattern we're eliminating. Disconnected from content.

**After rewrite (Pass/Strong version):**
```
2天
0行 Swift 經驗
1個完整的 iOS app

靠 Claude Code 從頭到尾生出來的
中間差點放棄了三次

但最扯的是——審核一次就過了

你有沒有用 AI 做出什麼自己都嚇到的東西？
```

### RED Fail Example

**Topic:** "AI tool that helps agents respond to overseas buyers faster"

**Fail version:**
```
Title: 分享一個好用的工具

今天想分享一個AI工具給大家
這個工具可以幫助仲介和海外買家溝通
我覺得很好用
有興趣的可以試試看
```

Why each pillar fails:
- **Hook:** Title has no keywords. "分享一個好用的工具" won't surface in search. No curiosity gap.
- **Retention:** No headers. No structure. Wall of short sentences. No reason to complete.
- **CTA:** "可以試試看" is passive. No save trigger. No engagement question. No hashtags.

**After rewrite:**
```
Title: AI回覆工具｜海外買家仲介省了3小時的祕密

## 問題
每天花多少時間回覆海外買家的問題？
語言、時差、條件解釋——加起來很可怕

## 我找到的解決方案
[AI工具名稱] — 專為跨語言地產溝通設計
自動翻譯 + 本地化語氣調整 + 文件摘要

## 實際測試結果
原本：每封郵件15-20分鐘
現在：3-5分鐘
一週省了超過3小時

## 值不值得用？
優點：[specific pros]
缺點：[honest cons]

你現在怎麼處理海外買家的溝通？收藏這篇，之後換工具的時候可以參考 👇

#海外買家 #房產仲介 #AI工具 #澳洲房產 #地產科技
```

### Instagram Fail Example

**Topic:** "AI tool for overseas buyer agents"

**Fail version:**
```
Slide 1: "AI for Real Estate"
Slides 2-8: Long paragraphs of text about how AI is changing real estate
Final slide: "Follow for more content!"
Caption: "AI is transforming real estate. #realestate #AI"
```

Why each pillar fails:
- **Hook:** Slide 1 doesn't answer "is this for me?" Too broad, not specific to overseas buyer agents.
- **Retention:** Long text on slides kills swipe momentum. No visual progression.
- **CTA:** "Follow for more content" is generic. No save, no DM, no share driver.

**After rewrite:**
```
Slide 1: "I cut overseas buyer onboarding from 3 hours to 18 minutes"
Slides 2-3: Before — what the process looked like (specific steps)
Slides 4-6: After — the AI workflow, one step per slide
Slide 7: The unexpected part — what changed beyond just speed
Final slide: "Save this + DM me 'AGENT' for the full workflow doc"
Caption: "3 hours → 18 minutes. The workflow for agents working with overseas buyers. Link in bio. #PropTech #RealEstateAI #OverseasBuyers"
```

### X Fail Example

**Topic:** "Agents not using AI for overseas buyers"

**Fail version:**
```
I think real estate agents who work with overseas buyers should consider using AI tools to help with their workflow. It could save a lot of time. What do you think?
```

Why each pillar fails:
- **Hook:** "I think real estate agents...should consider" — hedged, slow, zero scroll-stop.
- **Retention:** One undifferentiated block. No punch. Padded with filler.
- **CTA:** "What do you think?" anchored to nothing specific. Invites no real discussion.

**After rewrite:**
```
Overseas buyer agents who aren't using AI for client comms in 2026 are spending 8-10 extra hours per week on things that should take minutes.

The fix isn't complicated. The barrier is just knowing what to build.

What's the most time-consuming part of your overseas buyer workflow?
```

### LinkedIn Fail Example

**Topic:** "How AI helped with overseas buyer onboarding"

**Fail version:**
```
I wanted to share something that has been really helpful in my work with overseas property buyers. AI tools have changed how I approach the onboarding process. I think more agents should look into this. There are many tools available and I have found some of them to be quite useful. If you are interested in learning more, feel free to reach out.
```

Why each pillar fails:
- **Hook:** "I wanted to share" is the worst LinkedIn opener. First 210 chars burn entirely on setup with zero payoff.
- **Retention:** One long paragraph. Unreadable on mobile. No line breaks, no whitespace.
- **CTA:** "Feel free to reach out" is vague, low-intent. No specific question, no expertise invitation.

**After rewrite:**
```
The overseas buyer onboarding process at most agencies is broken in a way that AI could fix in a week.

I know because my sister runs it — and before we built a simple AI workflow, she was spending 3 hours per new client just on intake.

Here's what the old process looked like:

- First call: 45 minutes explaining FIRB rules, stamp duty, settlement timelines
- Follow-up email: 20 minutes drafting a bilingual summary
- Document collection: another 30-45 minutes chasing and translating

Total: 2.5 to 3 hours per client, before any actual deal work.

We rebuilt it with three AI components. Now it takes 18 minutes.

I'll share the workflow in detail this week.

But I'm curious — if you work with overseas buyers, what's the step that eats the most time?
```
